# Saxon-HE runtime

`Saxon-HE-10.9.jar` is the Saxon Home Edition runtime used to execute the pinned CIUS-RO XSLT 2.0 validation stylesheets. SHA-256: `491d8edf4ec811d15c2b2417b007218b9b938f15e4dfbad004025beb4e70e960`.

Saxon-HE is distributed under the Mozilla Public License 2.0. Upstream project and licence information: <https://github.com/Saxonica/Saxon-HE> and <https://www.mozilla.org/en-US/MPL/2.0/>. Java 21 is required by the development and CI configuration. Production must provide a supported Java runtime and the `EFACTURA_JAVA_BINARY` path.
