# ING statement fixtures

`ing-ron-layout-synthetic.pdf` and `.json` contain invented values only. They model the observed ING Romania account-statement labels, signed debit column, comma-grouped decimal formatting, multiline transaction descriptions, foreign-currency detail text, blank counterparty and page continuation. They are not extracts of the owner-supplied statement and do not validate real transaction values.

The source PDF and raw extracted text are intentionally excluded because they contain sensitive financial and personal data. See `docs/bank-statements/ing-statement-format-v1.0.md` for the versioned source-observed specification and field-confidence register.
